Los Santos GPS v4.1 — sabitleme ve görsel düzeltme

- Önceki suyun her yerine yayılan desen kaldırıldı. Kıyı kenarları boyunca sınırlı (~10-60 m), yarı saydam mavi bantlar kullanılıyor. Gerçek batimetri değil; kıyıya bağlı stilizasyon.
- Ağaç/landmark modelleri harita koordinatına sabitleniyor, aynı model her yenilemede silinip yeniden kurulmak yerine kimliğiyle korunuyor.
- Model renkleri gri, soluk çamur/granit tonları; haritayla uyumlu.
- Gece aydınlatması küçük bina cephelerini de hedefliyor; minimum kenar ve bina yüksekliği eşiği indirildi, görünen bina limiti artırıldı.
- Asıl bina geometrisi sokakta yoksa bu veri kaynağının eksikliğidir. Eksik OSM bina ayak izlerini tahmin ederek yanlış bina oluşturmayız. OpenStreetMap'e katkıyla düzeltilebilir.
- Prototip olarak model çeşitleri sınırlı; gerçek yapıların ayrı ayrı hazırlanmış ayrıntılı modeli değildir.
- Harita veri servisi / üçüncü parti kütüphaneler internet bağlantısı gerektirir.

Kontrol: JavaScript sözdizimi + ZIP bütünlüğü. Canlı GitHub Pages/iPhone görsel doğrulaması yapılmadı.
